## Overview

This repository documents my Week 2 cybersecurity internship work at *NetworkWalks*. It covers practical learning and research in web reconnaissance, Google Hacking Database (GHDB), Google Dorking, network discovery, and network scanning using Nmap and Zenmap.

The projects focus on understanding reconnaissance techniques, identifying publicly indexed educational resources, discovering live hosts on a local network, and documenting findings responsibly.

## Projects Included

### 1. W2-PM2 – GHDB-Based Footprinting Attacks

*Module:* Elective

*Topics Covered:*
- Introduction to Google Hacking Database (GHDB).
- Understanding Google Dorking and advanced search operators.
- Learning how search operators can identify publicly indexed information.
- Researching publicly accessible mathematics educational PDFs.
- Understanding the security risks associated with exposed information.
- Documenting methodology, findings, and scope limitations.

*Key Learning Outcomes:*
- Understand how search engines index publicly accessible content.
- Recognize the importance of responsible reconnaissance.
- Understand how exposed information can create security risks.
- Apply search operators for controlled and educational research.

*Scope and Limitations:* This project documents public educational-resource research. Camera-related testing was not performed because an instructor-approved lab environment was not provided.

### 2. W2-PM5 – Zenmap-Based Network Scanning

*Module:* Essential

*Tools Used:*
- Nmap 7.98
- Zenmap
- Ubuntu Linux
- Terminal

*Activities Performed:*
- Identified the local network range.
- Performed host discovery using Nmap.
- Scanned the local subnet 192.168.43.0/24.
- Identified active devices on the network.
- Reviewed scan output and documented the discovered hosts.
- Prepared a network topology overview.

*Actual Scan Summary:*

| Parameter | Result |
|---|---|
| Tool | Nmap 7.98 / Zenmap |
| Operating System | Ubuntu Linux |
| Network Range | 192.168.43.0/24 |
| Total IP Addresses Scanned | 256 |
| Live Hosts Discovered | 2 |
| Gateway | 192.168.43.1 |
| Local Machine | 192.168.43.100 |

*Key Learning Outcomes:*
- Understand network discovery and host enumeration.
- Identify active devices within a local subnet.
- Interpret basic Nmap scan results.
- Understand the role of network scanning in security assessments.
- Document network discovery findings.
